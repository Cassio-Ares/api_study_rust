# Service
- fala com regras  (lógica de negócio, validação)

## Result<Payment, Box<dyn std::error::Error>> 

- Result já tratamos em model mas basicamente é um enum com <Ok, Error>
 
  * Payment -> OK

  * Box ->  Rust precisa saber o tamanho de cada tipo em tempo de compilação mas dyn pode ter diversos tamanhos
  box resolve isso colocando erro no HEAP (memória dinâmica) e guarda só um ponteiro de tamanho fixo (lê-se: "um ponteiro para qualquer coisa que seja um Error")

  * dyn -> significa não sei o tipo de erro em tempo de compilação, aceita QUALQUER tipo que implemente o trait Error "dyn std::error::Error" (lê-se: "qualquer coisa que seja um Error")


- validate() -> retorna ValidationErrors ou
        o `?` converte automaticamente para Box<dyn Error>

````
new_payment.validate()?;
````

- repository -> retorna OK ou sqlx::Error
   o `?` converte automaticamente para Box<dyn Error>

```` 
payment_repository::create_payment(pool, new_payment).await?;
````


- .into() ->  String vira Box<dyn Error> com .into()

````
return Err("Amount to refund is greater...".into());
````

* Os três tipos diferentes de erro todos cabem no mesmo Box<dyn Error> ✅


## Service

### Service Formato mais simples 
- tratamento de erro usar (pool, new_payment).await?;

````
// Sem map_err - erro genérico e dificil de debugar

let payment = payment_repository::get_all_payments(pool).await?;

// Se falhar o log mostra algo como:
// -> "error returned from database"
// -> "connection pool timed out"
// Você não sabe ONDE no código falhou
````

````
// Pool de conexões com o banco
use sqlx::PgPool;

// Tipo UUID para identificar e tipagem
use uuid::Uuid;

// Trait que habilita o .validate() nos models
use validator::Validate;

// Importa os models necessários
use crate::models::payment::{Payment, NewPayment};

// Importa o repository — o service não fala com o banco diretamente
use crate::repositories::payment_repository;

pub async fn create_new_payment_service(
  pool:&PgPool,
  new_payment:NewPayment
)-> Result<Payment, Box<dyn std::error::Error>>{
  // Valida os dados antes de qualquer coisa
  // Aqui o compilador usa o 'impl Validate' que foi criado no validator, o impl Validate for NewPayment basicamente ensina o model NewPayment a se validar
  // "?" retorna o erro imediatamente para handler
  new_payment.validate()?;

  // Só chega aqui se a validação passou
  // Delega a criação para o repository
  let payment = payment_repository::create_payment(pool, new_payment).await?;

  Ok(payment)
}

pub async fn get_all_payments_service(
  pool:&PgPool
)-> Result<Vec<Payment>, Box<dyn std::error::Error>>{

   // Service só repassa para o repository
   // Sem lógica extra pois é uma listagem simples
   let payments = payment_repository::get_all_payments(pool).await?;

   Ok(payments)
}

pub async fn get_payment_by_id_service(
    pool: &PgPool,
    uuid: Uuid
) -> Result<Option<Payment>, Box<dyn std::error::Error>> {

    // Option porque o payment pode não existir
    // Some(payment) -> encontrou
    // None -> não encontrou
    let payment = payment_repository::get_payment_by_id(pool, uuid).await?;

    Ok(payment)
}
````

```
// Pool de conexões com o banco
use sqlx::PgPool;
// Tipo UUID para identificar pagamentos
use uuid::Uuid;
// Trait que habilita o .validate() nos models
use validator::Validate;

// Importa os models necessários
use crate::models::payment::{Payment, NewPayment};

// Importa o repository — o service não fala com o banco diretamente
use crate::repositories::payment_repository;

pub async fn create_new_payment(
    pool: &PgPool,
    new_Payment: NewPayment
)-> Result<Payment, Box<dyn std::error::Error>>{
    // 1. Validação de Entrada (O que o usuário enviou)
    new_payment.validate()?;

    // O '?' aqui já captura erros de infra (banco fora, erro de sintaxe)
    // .map_err() com mensagem descritiva
    let created_payment = payment_repository::create_payment(pool, new_payment)
    .await
    .map_err(|e| format!(
        "Erro ao persistir no banco: {}", e
    ))?

    // is_nil() no UUID❌ Redundante — new_v4() nunca é nil
    if created_payment.uuid.is_nil(){
        return Err(
            "Falha crítica: O banco não gerou um UUID para o pagamento".into()
        )
    }

    Ok(created_payment)
}


pub async fn get_all_payments_service(
    pool: &PgPool
) -> Result<Vec<Payment>, Box<dyn std::error::Error>> {

    let payments = payment_repository::get_all_payments(pool)
        .await
        .map_err(|e| format!("Erro ao buscar todos os pagamentos: {}", e))?;

    Ok(payments)
}

pub async fn get_payment_by_id_service(
    pool: &PgPool,
    id: Uuid
) -> Result<Payment, Box<dyn std::error::Error>> {

    let payment = payment_repository::get_payment_by_id(pool, id).await?;

    // ✅ Aqui faz muito sentido — transformar None em erro descritivo
    let payment = payment.ok_or("Payment not found")?;
    //                    ↑
    // ok_or → converte Option em Result
    // Some(payment) → Ok(payment)
    // None          → Err("Payment not found")

    Ok(payment)
}

pub async fn refund_payment_service(
    pool: &PgPool, 
    uuid: Uuid,
    amount_to_refund: f64
) -> Result<Option<Payment>, Box<dyn std::error::Error>>{

    let existing_payment = payment_repository::get_payment_by_uuid(pool, uuid)
    .await
    .map_err(|e| format!("Erro ao buscar pagamento para reembolso {}: {}", id, e))?;

    if let Some(mut payment) = existing_payment {
        if payment.amount < amount_to_refund{
            return Err("Amount to refund is greater than the original payment amount.".into());
        }

        payment.amount -= amount_to_refund;

        payment.status = if payment.amount == 0.0 {
            "refunded".to_string()
        } else {
            "partially_refunded".to_string()
        };

        payment.amount -= amount_to_refund;
        payment.status = if payment.amount == 0.0 {
            "refunded".to_string()
        } else {
            "partially_refunded".to_string()
        };

        let updated_payment = payment_repository::update_payment_for_refund(
            pool,
            id,
            payment.amount,
            payment.status
        )
        .await
        .map_err(|e| format!("Erro ao persistir reembolso do pagamento {}: {}", id, e))?;

        Ok(updated_payment)

    } else {
        Ok(None)
    }
}
```
